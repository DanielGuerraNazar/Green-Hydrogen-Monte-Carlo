# Modelagem Computacional para Análise de Incertezas na Produção e Armazenamento de Hidrogênio Verde

## 📌 Sobre o Projeto
Este projeto implementa uma modelagem computacional para calcular e analisar as incertezas de medição na cadeia de suprimentos de Hidrogênio Verde (H2V). A abordagem quantifica as incertezas nas equações de produção e distribuição utilizando o Método Clássico aliado a simulações de Monte Carlo.

Projeto desenvolvido no contexto do curso de Engenharia Elétrica da Universidade Federal de Uberlândia (UFU).

## 🚀 Funcionalidades
* Simulação de Monte Carlo aplicada aos processos da cadeia do H2V.
* Cálculo de propagação de incertezas na produção e armazenamento.
* Geração de resultados estatísticos para tomada de decisão.
